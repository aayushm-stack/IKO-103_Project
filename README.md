## 📌 Executive Summary & Purpose

Modern digital environments subject human attention to relentless algorithmic micro-targeting, resulting in chronic dopamine exhaustion, sleep disruption, and attentional fragmentation (*Vyākulatā*). Concurrently, frontline defense and paramilitary personnel face acute operational stressors—from hypothermic sensory deprivation at high altitudes to hypervigilant combat tension—with zero tolerance for digital noise or security vulnerabilities.

**BrahmaPath** is an offline-first, client-side digital therapeutics platform rooted in canonical **Indian Knowledge Systems (IKS)** (*Śrīmad Bhagavad Gītā*, *Kaṭha Upaniṣad*, *Caraka Saṃhitā*, and *Pātañjala Yoga Sūtra*). It replaces superficial streak counters and unpredictable AI chatbots with a **deterministic psychometric state machine** that monitors, balances, and stabilizes daily human equilibrium.

### Core Architectural Tenets:
1. **100% Offline-First & Privacy Sovereign**: Operates completely client-side. Zero cloud telemetry egress, zero tracking SDKs, and full OPSEC compliance for defense deployments.
2. **Deterministic State Machine (No Generative Hallucinations)**: Deliberately rejects conversational AI chatbots in favor of auditable, grounded psychometric state transitions.
3. **Compassionate Continuity (No Shame Loops)**: Eliminates punitive streak resets; replaces them with longitudinal Momentum dynamics that decay gently and reward recovery.
4. **Two-Stage Multi-Cohort Specialization**: Tailored behavioral telemetry for 6 distinct real-world civilian and frontline environments.

## 🏛️ Foundational Theory: The Vedic Science of Equilibrium

Rather than relying on modern commercial gamification, BrahmaPath structures mental health and self-regulation around time-tested canonical Sanskrit sciences:

### 1. *Ratha Kalpana* — The Chariot Allegory (*Kaṭha Upaniṣad* 1.3.3–4)
The human consciousness is modeled as a sacred chariot journey:
* **The Self (*Ātman*)**: The master and passenger of the chariot.
* **The Intellect (*Buddhi*)**: The charioteer holding the reins with discerning wisdom.
* **The Mind (*Manas*)**: The reins communicating guidance between intellect and senses.
* **The Senses (*Indriyas*)**: The spirited horses traversing the terrain of sensory objects.
* **The Dynamic Chariot States**: As daily balance shifts, the Chariot visually reflects one of four states: **Resting** (peaceful dawn or night stillness), **Calm** (*Sāttvika* harmony), **Brisk** (*Rājasika* dynamic effort), or **Galloping / Heavy** (*Tāmasika* friction requiring pause).

### 2. *Trayopastambha* — The Three Classical Pillars of Health (*Caraka Saṃhitā*)
Daily psychometric vitality is anchored upon the classical tripod of well-being:
* **Āhāra (Mindful Input & Nutrition)**: Pure, timely nutrition balanced with mindful digital sensory intake.
* **Nidrā (Restorative Sleep)**: Deep circadian restoration honoring natural biorhythms and tactical sleep splits.
* **Brahmacarya (Vital Energy Mastery)**: Conservation of creative, physical, and attentional vital reserves (*Ojas*).

### 3. *Pratipakṣa Bhāvana* — Cognitive Impulse Redirection (*Pātañjala Yoga Sūtra* 2.33)
When turbulent urges or emotional agitations arise:
* Instead of destructive suppression or guilt, the mind is immediately guided to cultivate the diametric opposite positive action (*Vitarka-bādhane pratipakṣa-bhāvanam*).
* Delivered via 48 rich, real-world **Śreyas Micro-Swaps** (e.g., Sūrya-Trāṭaka, physiological sigh breathing, cold-water wrist reset, cognitive reframing).

### 4. *Vyavasāyātmikā Buddhi* — Resolute Saṅkalpa (*Śrīmad Bhagavad Gītā* 2.41)
* Fragmented desire scatters attention into endless, exhausting branches (*bahu-śākhā hy-anantāś-ca*).
* BrahmaPath anchors resolve through a three-tier intention architecture: an immutable **Foundational Pledge**, actionable **24-Hour Immediate Intentions**, and **Horizon Milestones**.

### 5. *Sahyogi* Battle-Buddy Support & Institutional Tele-MANAS
* In high-friction moments, personnel can instantly initiate peer grounding (*Sahyogi* protocol) or access India's national crisis lifeline (**Tele-MANAS toll-free 14416 / 1800-891-4416**) with a single tap.

## 📱 Android Application (APK) Download & Installation

BrahmaPath runs as a native Android application powered by Capacitor, optimized for low battery usage and complete offline operation without requiring network permissions.

### APK Versions Overview

| Version | Status | Location | Target Theater & Description |
| :--- | :--- | :--- | :--- |
| **Version 1.0** | Available (Committed) | [`apk/BrahmaPath-v1.0.apk`](./apk/BrahmaPath-v1.0.apk) | **Civilian Prototype Build**: Covers foundational Stage 1 civilian life rhythms, core sādhanā tracking, and initial Chariot composure algorithms. |
| **Version 2.0** | Production Release (Upcoming) | `apk/BrahmaPath-v2.0.apk` | **Full Production Two-Stage Multi-Cohort Build**: Complete integration of Defense theaters (Glacier, Desert, CI Ops), 48 Śreyas micro-swaps, split-sentry circadian models, offline local notification scheduler, and Sahyogi crisis routing. *(Will be built into the `apk/` folder without overwriting v1.0)*. |

### Step-by-Step Installation on Android

1. **Locate or Download the APK**:
   * Navigate to the [`apk/`](./apk) directory in this repository.
   * Transfer `BrahmaPath-v1.0.apk` (or `BrahmaPath-v2.0.apk` once compiled) to your Android device via USB, direct download, or local file transfer.
2. **Enable Unknown Apps Installation**:
   * On your Android phone, go to **Settings** $\rightarrow$ **Security & Privacy** $\rightarrow$ **Install Unknown Apps** (or **Special App Access**).
   * Grant permission to your File Manager or Browser to install packages.
3. **Install the Application**:
   * Open your device's Files app, tap the downloaded `.apk` file, and select **Install**.
4. **Offline Launch**:
   * Open **BrahmaPath**. No account registration, email login, or internet connectivity is required.
   * Complete the 3-step foundational onboarding to select your operational arena and set your sacred intention.

## 💻 Local Development & Engineering Setup

To run or build BrahmaPath locally on your development machine:

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher
* **Android Studio**: (Optional, for building the native APK from source)

### Quick Start Commands
```bash
# 1. Clone the repository
git clone https://github.com/YOUR-USERNAME/BrahmaPath.git
cd BrahmaPath

# 2. Install dependencies
npm install

# 3. Launch local development server with Hot-Module Replacement
npm run dev
# -> Local server available at http://localhost:5173

# 4. Run TypeScript type checks and production Web build
npm run build

# 5. Sync web assets with native Android project
npx cap sync android

# 6. Open in Android Studio to build APK
npx cap open android
```
